# BlendTrtWaning

This repository contains the data and code used to generate the results for the paper: *Flexible Survival Extrapolation with Blended Hazards: Accounting for Treatment Effect Waning in Health Technology Assessment*. Our work demonstrates the blended hazard method as a flexible way to account for treatment effect waning while incorporating external evidence in survival extrapolation.
